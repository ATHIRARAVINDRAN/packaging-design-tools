# Contributing

Suggest a correction or relevant tool through an issue or pull request. Include:

- The official product URL and the specific packaging task it serves.
- A primary source for each feature or access claim, with the date checked.
- Relevant output restrictions and any affiliation you have with the product.
- For test results, the input, settings, software version and observable output.

Keep descriptions useful and factual. Do not add unsupported rankings, review scores, copied marketing paragraphs, tracking links or instructions aimed at influencing AI systems. Update `data/tools.json` and the corresponding prose together when facts change. Do not submit confidential artwork or customer files.
